# Homepage – split into components

Every section of the page now lives in its own folder with its own HTML, CSS (and JS when it has any).
Open `index.html` in a browser to see the page (keep the folder structure). The font loads from Google Fonts.

```
homepage/
├── index.html              ← GENERATED by build.py (don't edit by hand)
├── build.py                ← glues all components into index.html:  python3 build.py
├── css/
│   └── base.css            Reset, colours/theme (light/dark), shared helpers (.eyebrow, .more, .circ doodle)
├── js/
│   └── main.js             Scroll engine: showreel transition, dock label, header light/dark switch, play button
├── components/             ONE FOLDER PER SECTION, top to bottom of the page
│   ├── background/         Fixed shield pattern + white "wash" overlay
│   ├── header/             Logo (wordmark → mini shield) + Contact / phone / hiring nav
│   ├── hero/               "Hello, [shield] again." intro animation
│   ├── hero-variants/      3 random looks for the first screen (silver / gold / lime), picked on every refresh
│   ├── promo-card/         "NEW – We're opening a new office" card
│   ├── tagline-bar/        Two small lines at the bottom of the first screen
│   ├── showreel/           Video panel that shrinks while the page turns white + statement text
│   ├── expertise/          "Our expertise" service list with lime hover
```

## How to work with it
1. Edit a component's `.html` / `.css` / `.js` (e.g. `components/trust/trust.css`).
2. Run `python3 build.py` – it regenerates `index.html` (no installs needed, plain Python 3).
3. Refresh the browser.

Want a new section? Make `components/my-section/my-section.html` + `.css`, then add its name to
`PAGE` and `STYLES` in `build.py`.

## Things worth knowing
- **CSS load order matters** (list `STYLES` in build.py): later files win when two rules are equally specific.
- **Shared pieces** live in `css/base.css`: the `.eyebrow` label, the `.more` link and the hand-drawn `.circ` circle
  (used by both Awards and Inside). Each section only recolours them.
- **`main.js` looks up elements by class/id** (`.panel`, `.say`, `#work`, `#inside`, `.dock-exp`…), so keep those names
  if you rename things.
- Body theme classes toggled by JS: `light` (white sections), `dark` (Our work + footer), `sc` (scrolled),
  `foot` (last section), `exp` (inside expertise/approach/awards – changes the dock).
- Placeholders to replace: YOURBRAND / WOKINE wordmark, phone number, taglines, statement text.

## Random hero looks
Every refresh plays the SAME dark entry animation (bar, shield draw, Hello/again). When it ends (about 5.6s) the page fades
into that refresh's look (never the same one twice in a row): stays dark + silver, or becomes white + gold shields, or
grey + lime shield. `components/hero-variants/hero-variants.js` picks the look and triggers the fade; the looks live in
`hero-variants.css`. Force one for testing with `index.html?variant=gold` (silver | gold | lime).
To add a look, add its name in the `.js` list and a `html[data-variant="name"]` block in the `.css`.
